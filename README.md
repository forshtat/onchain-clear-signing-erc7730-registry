# ERC-8283 Clear Signing Registry

Reference implementation of [ERC-8283](https://ethereum-magicians.org/t/erc-8283-on-chain-registry-for-erc-7730-clear-signing-descriptors/28717),
an on-chain registry mapping contexts (contracts, factories, EIP-712 domains) to attested ERC-7730 Clear Signing descriptors.

**Not audited. The architecture is still changing and the documentation is being rewritten.**
The code in `contracts/` is the only source of truth for now.
